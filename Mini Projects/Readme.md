# 🧮 Python Calculator

A simple command-line calculator built with Python.  
Supports basic operations like addition, subtraction, multiplication, and division.

---

## 📋 Features

- Addition
- Subtraction
- Multiplication
- Division with zero-check
- User-friendly menu in terminal

---

## 🚀 How to Run

1. Make sure you have Python installed:
    ```bash
    python --version
    ```

2. Clone this repository (if not already cloned):
    ```bash
    git clone https://github.com/gitmshashank/Python_Project-Mini.git
    cd Python_Project-Mini
    ```

3. Run the calculator:
    ```bash
    python "Mini Projects/calculator.py"
    ```
